# Repository Instructions for `nanai-shiftjis-notepad`

This repository is a Windows-focused Rust application for reading and displaying Shift_JIS-encoded text.

## Key guidance for assistants

- Treat this project as Windows-first. Do not assume cross-platform packaging or runtime behavior.
- Preserve the existing Shift_JIS decoding logic in `src/file_process.rs`.
- Keep the UI implementation in `src/ui.rs` simple and centered using the existing `gpui` render pattern.
- When modifying shell or COM integration, inspect `src/lib_dll.rs` and `nanai-shiftjis-notepad-dll/src/lib_dll/` first.
- Do not change packaging manifests (`appxmanifest.xml`, `winapp.yaml`, `nanai-shiftjis-notepad.msix`) unless you understand MSIX and WinApp SDK integration.
- Prefer source-driven fixes over assumptions: use `Cargo.toml`, `AGENTS.md`, and implementation code as the primary references.
- For build and run guidance, rely on `cargo build`, `cargo build --release`, and `cargo run -- <path-to-shiftjis-file>`.

## When asked for help

- If the task involves Windows shell integration, inspect `src/lib_dll.rs` and `Cargo.toml` first.
- If the task involves packaging, inspect `appxmanifest.xml` and `winapp.yaml`.
- Keep changes minimal and aligned with the repo's current focus on reading and rendering Shift_JIS text.
